## 尚未完成的发布项

以下按影响优先级排序，均有具体代码依据，不以“需要人工验证”掩盖实现缺失。

1. **P1 — iCloud 恢复和账户隔离未完成。** `ModelContainerFactory` 使用不同的 `PromptiCloud` / `PromptiLocal` store，缺少合并/迁移机制；本地回退期间新增记录在下次打开 Cloud store 后可能不可见。`persistenceMode` 只表示启动时容器选择，不反映上传/下载、配额或账户状态；未实现账户切换暂停写入和重建 store。需要独立的数据迁移、账户隔离设计及双设备验证。
2. **P1 — 开放口语语义评估未完成。** `SpeechAnswerEvaluator` 仍是本地文字匹配；本轮修掉误判后，合理同义表达会保持 undetermined。缺少语义 rubric、可编辑转写、语速偏好和参考答案播放入口，不能宣称 FR-006 的语义反馈完整。
3. **P1 — 内容追溯与质量验收不足。** `QuestionRecord` 没有讲解 locale、Provider/model、prompt/schema/policy/catalog 版本、来源 fact ID、usage 等元数据；因此库存不能按讲解语言精确复用，内容政策升级无法按版本重审。目录事实缺少来源 URL、审核日期。输出审核只对整批返回一个安全 bool，缺少逐题语义/难度/唯一答案审核、跨批次与同步去重。
4. **P1 — 自定义 endpoint 的 DNS 边界尚未完成。** 本轮阻止了重定向和私网字面量，但公网域名解析到私网或 DNS rebinding 仍未防护，需要验证最终连接地址。
5. **P2 — 多空完形、罗马字/转写字段未实现。** `GeneratedQuestion` 只有一个 correctAnswer；本轮明确校验单空，UI/持久化没有多空结构。七种训练语言已覆盖，但目录没有地区 locale 变体与地区层级浏览。
6. **P2 — 自动补题/修复预算与 Apple 小批次未完成。** 已支持手动补题和部分题先开始，但不会一边作答一边补齐；没有字段级修复和完整的总时间/token 预算。Apple 将至多 20 题及整批审核放入单个模型请求，缺少面向短上下文的分批策略。
7. **P2 — 预生成管理仍不完整。** 已有每日题数预算与低耗检查，但缺少 token/请求用量展示、手动清空库存；BGTask 属于 README 已披露的当前边界。Today 默认题型/场景仍是固定组合，未保存并复用用户在 Practice 中选择的全部偏好。
8. **P2 — Apple 能力提示与 BYOK 探测有限。** 不可用 Apple 状态未完整呈现原因，目标讲解语言的 Apple 支持也未检查；`ProviderDetector` 尚未接入连接 UI，当前是用户手动选择协议后做最小探测。没有实际模型列表、探测时间和权限详情。真实 Apple/各家账户授权与额度尚未联调。
9. **P2 — 数据管理和发布工程未齐备。** 缺少删除全部学习数据、导出和生产 CloudKit schema/历史磁盘迁移验证；没有 CI workflow 和多语言内容评测集。UI 英语优先是 README 已披露边界，仍需决定是否接受与早期中英首发要求的差异。
