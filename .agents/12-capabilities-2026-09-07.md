# 2026-09-07 能力补齐

本轮按用户批准的四组能力推进：数据恢复与账户隔离、口语语义反馈、逐题质量审核与来源记录、多空与自动补题/用量管理。验收使用系统默认字号和常规布局。

## 已实现的行为

### 数据升级、恢复与账户边界

- 冻结 `PromptiSchemaV1`，新增 V2 及轻量迁移。题目新增讲解语言、结构化完形、口语 rubric、生成元数据、内容指纹及归档标记；答题新增题目快照、session ID、置信度、反馈和时区。V1 的未知讲解语言保持未知。
- 不同 iCloud 账户与未登录状态使用不同文件。启动先读取该身份的本地数据，异步校验 CloudKit 用户后启用同步；同一账户 `.none` 回退与 CloudKit 配置使用相同 URL。
- 不假定 opaque identity token 的序列化字节稳定，使用解档后的身份相等性，并以经验证的 CloudKit owner 映射恢复原账户文件。
- 身份变化重建根视图、取消旧练习/补题/语义任务并加载对应文件；打开失败时显示重试页，禁止继续在前一账户或临时库中练习。
- 旧 `PromptiCloud` / `PromptiLocal`、未登录数据及新身份确认前的临时本地数据保留，通过设置中的确认导入归属当前账户。按 UUID 幂等复制，保留原始事件、孤立事件及已有隔离标记；不自动导入另一个已确认账户的数据。
- 展示真实 CloudKit 事件状态、空间不足/未登录/离线原因及最近事件时间，按 store UUID 忽略旧库通知；不把一次事件成功描述为所有设备已收敛。
- 同步带来的相同事件 UUID 在统计中只计一次；题目相同 UUID 的隔离状态优先，库存按内容指纹避免重复呈现。历史记录不因去重而物理删除。

### 逐题审核与来源

- Remote 与 Apple provider 共用 Sendable 协议，测试可注入 fixture。
- 先做字段/选项/结构校验，再按客户端题目 UUID 审核安全、目标/讲解语言、场景、自然程度、答案有效性与唯一性、难度。缺少决定的题目不通过；未知或重复审核 ID 拒绝该次审核，合格题目不被普通单题拒绝连带淘汰。
- 记录 job/batch UUID、provider/model、prompt/schema/policy/catalog 版本、完成时间、通过的检查、实际引用的目录事实 ID 与文字快照。不保存 Key、认证头、完整系统提示或隐藏推理。
- 来源 ID 必须来自输入目录事实。这里记录的是应用内目录的来源与版本，不代表完成了目录所有事实的外部来源核验。
- 新题必须带结构化完形或口语 rubric（对应题型）；保留旧单空题的读取与练习能力。

### 口语与完形

- 口语按意图和必要细节允许同义表达，明确考虑否定、地点、数量和实体差异；不使用文字相似度判断语义，也不从文字推断发音。
- 转写可编辑；用户确认过的文字不再受原 STT 置信度限制。未编辑的低置信转写、空输入、模糊判定、非法 verdict 或服务故障都不计分。
- 异步提交期间不能重复提交、跳题或报告；退出/失活取消评估，迟到响应不会保存 attempt。
- 增加参考答案播放和本机慢/正常/快三档语速偏好。原始录音不保存或同步。
- 1–3 个结构化空位，每空独立选项，全部选择后才可提交；保存每空选择并检查全部答案。题干展示已选文字，反馈标记各空的正确与错误选项。

### 自动补题、库存与用量

- Remote 首批最多 3 题，Apple 最多 2 题。先开始已审核题目，练习时继续按小批次追加；当前题对象与顺序保持稳定。
- 进度以请求总量为分母，同时显示实际已备题数。到达当前末尾时等待审核；失败可重试或以实际完成量结束，已有题目与答题事件保留。
- 每个生成作业最多额外再生成一个小批次；每个 provider 请求至多 60 秒，整段生成/自动补题作业 180 秒，口语评估 45 秒。通过协作取消结束超时调用；不对认证、额度或网络错误无限重试。
- 预生成按已预扣题数请求，不进行额外再生成，保持每日预算语义。保留 Wi-Fi/电量/前台限制；清空未练库存会暂停预生成并写入可同步的归档标记，不删除已答历史。
- 保存和取库存按目的地、训练语言、讲解语言及内容指纹去重，匹配所选难度。最多携带 30 条已有题干帮助模型避免跨批次重复。
- 本机账本保留最近 1,000 次实际请求，包括生成、审核、语义反馈、连接探测、失败和协议降级；先登记请求，响应后更新同一条记录，重启不丢失。
- 解析 Responses/Chat/Anthropic 的实际 input/output token；未提供用量保持 nil 并显示未知，Apple 不伪造 token。批次 token 不摊到每道题而重复累加，也不估算价格。

## 尚需发布前验证及本轮范围外工作

- 真实 CloudKit A/B 账户切换、离线恢复、双设备同步、配额故障及生产 schema 部署。SwiftData 不公开底层 coordinator 的主动卸载接口，本轮依靠容器/视图生命周期与系统 CloudKit mirroring 的账户处理；模拟器文件隔离测试不能证明系统同步在真实账户切换瞬间的行为。
- 真机录音、中断与系统 Speech 服务，实际 Apple Foundation Models 的上下文与语言支持，各服务商真实账户/余额/授权，以及七语言语义和题目质量。
- 原复核中的 endpoint DNS 最终连接地址验证、外部事实来源 URL/审核日期、地区层级与罗马字、字段级修复、多语言离线评测、全部数据导出/删除、CI、自动协议识别等未纳入这四组能力，仍保留为独立事项。
- Today 的默认题型/场景仍使用固定组合；未接入系统 BGTask 调度。用户在设置中开启预生成才会产生提前准备请求。
