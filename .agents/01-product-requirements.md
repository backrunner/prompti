# Prompti 产品需求文档

## 1. 产品定义

Prompti 是一款面向短期游客的情境式语言学习应用。用户选择具体旅游目的地、当地可用语言、场景、难度和题量后，应用通过 Apple 设备端模型或用户自备 API Key（BYOK）的模型生成完形填空、QA 选择题和口语 QA，帮助用户在出发前练习真实、简短、可复用的表达。

Prompti 的核心价值不是提供完整语言课程，而是让用户在有限时间内获得“到达后立即能用”的交流能力。

## 2. 目标用户与使用时机

### 2.1 主要用户

- 即将前往陌生国家或城市，希望快速掌握旅游沟通用语的游客。
- 已有一定语言基础，希望强化特定城市、饮食、交通或文化语境的用户。
- 在意数据隐私，愿意使用 Apple 设备端模型或自行管理模型密钥的用户。

### 2.2 典型时机

- 行前一到四周：按目的地系统训练。
- 旅途中：随机一题、错题回顾、临时场景突击。
- 每日短练：完成少量题目并保持打卡。

## 3. 产品原则

1. **目的地优先**：内容围绕城市或地区，而不是只有国家级泛化内容。
2. **实用优先**：短句、真实任务、可立即使用；避免文学性或考试化内容。
3. **安全优先**：输入和输出均审查，失败时关闭通路，不展示未经验证内容。
4. **用户掌控**：模型、语言、难度、场景、题量、预生成与费用风险均可见可控。
5. **隐私优先**：API Key 永不进入 iCloud、日志、分析或崩溃报告。
6. **低压力**：允许跳过和报告问题；跳过不算错；反馈强调进步而非惩罚。

## 4. MVP 范围

### 4.1 P0：发布必须具备

#### FR-001 目的地与语言

- 用户必须能按国家、地区、城市浏览或搜索目的地。
- 一个目的地必须能声明多种可训练语言和具体 BCP-47 locale。
- 用户必须选择“学习语言”和“讲解语言”；两者相互独立。
- 首期支持 `en`、`ja`、`ko`、`ru`、`de`、`es`，并允许目的地限定变体，如 `en-GB`、`es-ES`。
- UI 和数据模型必须支持非拉丁文字及可选的罗马字/转写，不得按 ASCII 假设截断或验证文本。

验收：东京可选择日语或英语；巴塞罗那可选择西班牙语或英语；选择变化后可用场景和模型能力随之重算。

#### FR-002 场景选择

- 内置通用场景至少包含：购物、就餐、公共交通、问路、景点/购票、酒店、打车、外卖、紧急求助。
- 目的地目录可追加当地场景，如特色餐饮、市场、交通卡、地方景点和地域表达。
- 用户可多选场景，也可输入一个自定义场景。
- 自定义场景必须短小、单一意图、经 LLM 分类审核后才可保存和用于生成。
- 涉及露骨色情、性服务、政治宣传/动员、极端主义或提示词注入的场景必须拒绝。

验收：未通过审核的自定义场景不会进入本地题库、同步或生成提示词，并给出非指责性的原因分类。

#### FR-003 难度

- 提供四档用户可理解的难度：生存沟通、基本交流、自然交流、流畅表达。
- 内部映射到可测试的语言约束，而不只把难度标签发给模型。
- 难度影响词汇范围、句长、语速、干扰项相似度、提示数量和答案开放程度。

建议映射：生存沟通 A1；基本交流 A2-B1；自然交流 B1-B2；流畅表达 B2-C1。该映射仅用于出题控制，不宣称为正式 CEFR 测评结果。

#### FR-004 题型与题量

- 支持单空/多空完形填空、文本 QA 选择题、口语 QA。
- 用户可设置每组题量，MVP 建议范围 3-20，默认 5。
- 提供“随机一题”快捷入口。
- 开启练习的次数不设产品内上限，但受用户模型配额、网络和成本限制。

#### FR-005 生成与恢复

- 开始练习后必须展示明确的生成进度状态，不显示虚假的精确百分比。
- 生成过程必须支持取消。
- 结构错误、内容不合格、模型拒答、网络失败、限流、认证失败、余额不足和超时必须有不同恢复建议。
- 单批生成可自动修复或重试，但必须有次数、时间和 token 上限。
- 若只生成部分合格题目，用户可选择先开始，应用在后台补足；不得静默混入未审核题目。

#### FR-006 作答

- 每题必须允许提交、跳过和报告“题目可能有误”。
- 跳过不计正确或错误；报告有误的题目进入隔离状态，不再随机出现。
- 选择题提交后展示正确答案、简短解释和实用表达。
- 口语题展示目标语言提示，可播放系统语音，录音后给出转写和基于语义的反馈。
- MVP 不得把转写相似度包装成专业发音分数。

#### FR-007 历史、错题与统计

- 保存题目快照、作答记录、跳过/报告记录、生成元数据和安全/质量版本。
- 错题集支持按目的地、语言、场景和日期筛选并重新练习。
- 展示正确数、错误数、正确率、练习题数、连续打卡和每日完成情况。
- 统计从不可变作答事件派生，不能依赖容易产生 iCloud 冲突的可变累计计数器。

#### FR-008 iCloud

- 题库、作答历史、错题和统计必须默认存入 SwiftData 并通过用户的 iCloud private database 同步。
- iCloud 不可用时必须可本地使用，并展示同步状态；恢复后自动收敛。
- API Key、认证头和敏感 Provider 配置不得进入 iCloud。

#### FR-009 AI 配置引导

- 首次启动必须判断 Apple 系统模型的系统、设备、地区、就绪状态和目标语言支持。
- 完全不支持的设备/系统/地区隐藏 Apple 选项，并强制完成 BYOK 配置后才能生成。
- 设备支持但模型尚未下载完成时可显示不可用状态与原因；在其可用前仍需 BYOK 才能生成。
- Apple 模型可用且支持目标语言时默认推荐设备端模型。
- BYOK 至少支持 OpenAI Responses、OpenAI Chat Completions 和 Anthropic Messages；自定义 OpenAI-compatible endpoint 作为兼容模式。
- 应用必须执行连接测试和协议识别，并在自动识别置信度不足时要求用户明确选择，不得“猜测成功”。

#### FR-010 成本透明

- 后台/空闲预生成默认关闭。
- 启用前必须说明：会在未立即作答时调用模型，可能额外消耗 token 和产生费用。
- 设置目标库存、每日最大生成题数、仅 Wi-Fi、低电量时暂停和手动清空队列。
- 对无法可靠获得价格的自定义模型只展示 token/请求用量，不估算货币成本。

### 4.2 P1：MVP 后优先增强

- Gemini `generateContent` Provider。
- 多目的地旅行计划与离线下载包。
- 更细粒度的听力题和多说话人音频。
- 用户反馈驱动的题目质量模型与匿名、明确同意的遥测。
- 小组件、App Intents、每日提醒。
- 可选的第三方语音评分服务。

### 4.3 明确不做

- 不把 Prompti 作为签证、法律、医疗、治安或实时旅行资讯来源。
- 不生成实时票价、营业时间、法律要求或安全警报；这类内容需要权威数据源。
- 不代理或托管用户 API Key，不提供共享服务端密钥。
- 不保证 iOS 后台任务按时运行。
- 不根据有限练习结果授予正式语言等级。
- 不在 MVP 构建社交、排行榜、用户公开内容或内容市场。

## 5. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 隐私 | 无账号也可使用；Keychain 本机保存；默认无第三方分析；网络请求清楚标注 Provider |
| 安全 | HTTPS、ATS、阻止本地/回环自定义 endpoint、日志脱敏、输入输出双重审查 |
| 可靠性 | 所有生成可取消；失败可重试；部分成功可用；持久化写入显式保存 |
| 性能 | 主线程不做网络、JSON 校验、音频处理；列表稳定 identity；启动不等待 CloudKit 完成 |
| 无障碍 | Dynamic Type、VoiceOver、Reduce Motion、Increase Contrast、44pt 触控区域 |
| 本地化 | UI 文案与训练语言解耦；支持复数、RTL 扩展和多书写体系 |
| 可维护性 | Provider contract fixtures、prompt/schema 版本化、feature-first 目录、Swift 6.2 严格并发 |
| 开源 | 不提交密钥、付费内容或不可再分发资产；明确许可证和贡献规范 |

## 6. 成功指标

MVP 阶段优先采用设备端、隐私友好的指标；没有用户明确同意不得上传。

- 首次配置完成率。
- 从点击开始到首道合格题可作答的中位时长。
- 生成批次合格率、修复率、Provider 错误率。
- 每次会话完成率、跳过率、题目报告率。
- 7 日内复习错题的用户比例。
- 每个目的地/语言/难度组合的人工质量通过率。
