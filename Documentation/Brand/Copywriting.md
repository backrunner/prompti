# Prompti 文案规范与市场文案

更新：2026-09-08。适用于中文品牌物料、产品介绍、商店文案和 App 界面。英文文案独立撰写；中文不逐字翻译英文口号。

## 商店介绍

出国旅行，想提前练练怎么点餐、问路、办理入住？在 Prompti 选好目的地和语言，就能围绕这些常见场景开始练习。

**练习你会用到的对话。** 选择城市和旅行场景，也可以添加自己的目的地，或描述一个想练习的场景。自定义场景通过审核后即可使用。

**按自己的情况安排练习。** 从入门沟通到流畅表达，提供四档难度。每组可以设置 3–20 道题，也可以随机练一题。填空题、选择题和口语练习帮助你熟悉常用说法，翻译与讲解可选中文或英文。

**说一遍，再看看怎么改。** 口语练习支持朗读题目、录音作答和编辑识别文字。反馈会检查意思是否准确，并提供参考答案。识别或评估结果不确定时不计分，也不提供专业发音评分。

**不熟悉的表达，回来再练。** 答错和跳过的题目可以复习，学习记录与进度随时查看。可以跳过暂时不会的题目，也可以反馈题目问题。

**选择自己的 AI 模型。** 符合条件的设备可使用 Apple 设备端模型，也可以登录支持的模型服务商账号或填写 API 密钥。服务商可能收取模型使用费用；提前准备题目默认关闭，开启后可能产生额外费用。

学习数据保存在本机，iCloud 可用时可同步。API 密钥仅保存在本机钥匙串中，不会同步到 iCloud。Prompti 开源，使用原生 SwiftUI 开发。

以上为仓库内可供使用的商店文案，尚未发布到 App Store。设备端模型的可用性以系统、设备、地区和语言支持情况为准。

## 端内语气与用词

- 先说具体内容：城市、点餐、问路、回答、题目。不要用“远方”“路线”“新篇章”等抽象比喻代替功能含义。
- 按中文习惯写完整的短句。标题简明，按钮写操作，说明补充必要信息；不刻意切成排比短句，不堆叠“从容”“自信”。
- 提示说清发生了什么，以及可以怎么继续。例如“模型繁忙或请求次数过多，请稍后重试”。技术字段保留准确名称，普通流程避免“库存”“响应”“语境打包”等工程术语。
- 完成一组练习不等于掌握语言。完成页使用“练习完成”“先练到这里”“全部答对！”等短标题，不再附加鼓励段落；“全部答对！”只用于整组全对。没有计分结果时显示“未计分”，不暗示表现优秀或已能应付所有场景。
- 不把题目反馈称为“举报”。不把语音识别、语义反馈包装成专业发音评分。隐私、费用与同步说明必须与真实行为一致。

| 概念 | 统一用词 |
| --- | --- |
| 题型 | 填空题、选择题、口语 |
| 难度 | 入门沟通、基本交流、自然交流、流畅表达 |
| 未答题目 | 待练题目 |
| 作答历史 | 练习记录；复习筛选项为“全部记录” |
| 示例 / 标准表达 | 参考答案 |
| 题目问题反馈 | 反馈题目问题；筛选项为“已反馈” |
| 录音与转写 | 录音作答、语音识别结果 |
| 无可靠评分 | 未计分 |
| 复习后答对 | 最近答对，不宣称“已掌握” |

## 维护方式

App 文案的运行时来源是 `Prompti/Resources/Localizable.xcstrings` 和 `InfoPlist.xcstrings`，保留变量类型与数量。现有英文键保持稳定；不能因中文改写而改变场景 ID、难度约束、模型提示词、统计或持久化字段。

不同语境不能仅因英文单词相同而共用翻译键。例如学习记录的 Review 是“复习”，生成阶段的质量检查是“审核”，添加自定义场景的按钮是“添加”。欢迎页中文主句在逗号后换行，避免把“旅行常用语”拆开。

中文主句变化时同步欢迎页、设置页、README、品牌规范与 `Preview.html`，重新导出 `Preview.png`。图标没有文字，本轮不改图标生成器或重绘品牌标识。旧验收截图作为历史记录保留，新截图单独存放并注明日期、环境、来源与范围。
