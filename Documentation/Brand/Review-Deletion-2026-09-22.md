# 错题与答题历史删除验收

日期：2026-09-22。

错题和历史列表使用原生 `List` 的左滑删除，内容卡片继续使用共享 `promptiSurface()`，滚动边缘复用 `promptiScrollEdges()`。左滑只露出删除按钮，必须点击按钮才执行单条删除。

顶部提供“一键清空”，有筛选时显示“清空筛选结果”。批量删除先确认题目数量和对学习进度的影响，取消保留原数据，空列表禁用操作。清空按当前分类、筛选范围内的题目 ID 执行，不扩展到确认之后新出现的其他题目。

每行代表一道题的全部作答：删除会同时从错题、历史和派生统计中移除相关作答。保留题目的库存墓碑，避免重新进入待练题库；不修改原题内容。删除时再次检查隔离和报告状态，保护确认期间同步到达的报告。数据操作显式保存，失败回滚并显示本地化提示。

## 实际界面

iPhone 17e 模拟器，iOS 27.0（24A434），系统默认字号。英文浅色、简体中文深色检查左滑、清空确认、取消、空状态及统计联动，英文另覆盖筛选清空后筛选外记录仍保留。

本机运行时的系统外观切换未可靠传入 App；因此使用仅在 Debug 且独立 UI 测试数据模式下生效的 `-prompti-ui-light` / `-prompti-ui-dark` 参数，为实际 App 注入对应外观。正常启动和 Release 继续跟随系统，无新增用户设置。本轮验证对应外观的实际渲染，不宣称已验证系统外观自动切换。

已目视检查卡片、左滑删除、确认文案、筛选状态和清空后空状态。13 张原始 App 截图及结果包来源见 [截图清单](ReviewDeletionScreenshots/manifest.json)。

## 验收边界

使用独立模拟器和本地 Demo fixtures，不操作用户的真实学习数据，不调用真实模型。本轮不覆盖真机、iPad、旧版 iOS、人工 VoiceOver 或两设备真实 iCloud 同步；本地持久化回归不能证明跨设备同步已经验收。
